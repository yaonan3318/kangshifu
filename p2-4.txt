P2-4：轻量 Chatflow
不建议立即开发 Dify 式自由拖拽画布，先实现可配置的流程节点和固定画布。
第一版节点
- 开始节点
- 问题分类节点
- 问题改写节点
- 知识库检索节点
- Reranker 节点
- 条件判断节点
- 本地模型节点
- DeepSeek 节点
- Harness 节点
- 答案校验节点
- 最终回答节点
基础能力
- 节点输入、输出变量
- 节点启用和停用
- 条件分支
- 节点失败处理
- 超时处理
- 调试运行
- 展示每个节点耗时
- 保存草稿
- 发布版本
- 回滚历史版本
- 不同助手绑定不同 Chatflow
推荐默认流程
开始
 → 问题分类
 → 上下文补全
 → Multi-query
 → 权限过滤
 → 混合检索
 → Reranker
 → 置信度判断
    ├─ 资料充分 → 本地千问 → 引用校验 → 回答
    ├─ 资料不足且允许DeepSeek → DeepSeek → 标记通用知识 → 回答
    ├─ 运维任务 → Harness → 人工确认
    └─ 无法回答 → 缺失知识提示
