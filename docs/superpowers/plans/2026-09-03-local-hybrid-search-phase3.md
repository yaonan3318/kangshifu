# 第三期：本地混合检索实施计划

## 目标

在第二期解析与切片结果之上，增加完全本地运行的关键词检索、语义向量检索与 RRF 融合排序。只有完成索引的文档参与搜索，结果必须展示文档来源、片段位置、命中方式和 OCR 信息。

## 实现步骤

1. 为 `document_chunks` 增加 `tsvector` 和 `vector(1024)` 字段，建立 GIN 与 HNSW 索引；迁移时为历史 `PARSED` 文档创建索引任务。
2. 扩展文档状态和任务类型，解析成功后自动创建 `INDEX` 任务。Worker 根据任务类型分别执行解析或索引，并在失败时写入可见状态。
3. 使用 jieba 处理中文关键词，使用 `BAAI/bge-m3` 生成归一化向量。模型缓存到本地资料库目录，避免每次启动重复下载。
4. 新增搜索 API：关键词和向量各取 30 个候选，通过 RRF 合并，默认返回前 10 条；过滤条件同时应用于两路查询。
5. 新增 Vue 搜索页，展示查询框、文件类型筛选、结果片段、来源位置和“关键词/语义/混合”命中标签，并保留资料库入口。
6. 更新安装脚本与使用说明。安装阶段预下载本地向量模型，迁移后 Worker 自动处理现有文档。

## 本地验收

1. 在 Mac 执行 `./scripts/setup.sh` 和 `./scripts/start.sh`，确认模型下载和数据库迁移成功。
2. 观察 `.run/worker.log`，确认历史文档状态由 `PARSED` 变为 `READY`。
3. 分别用文档原词、同义表达、中英文混合查询验证关键词、语义和混合命中。
4. 验证搜索结果可追溯到正确文档、片段及页码/工作表/幻灯片，并确认 OCR 片段带有标记。
